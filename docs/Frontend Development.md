# JARI Frontend Development Specification

This project’s primary product and implementation reference is the frontend specification in [frontend-documentation.md](frontend-documentation.md).

The requirements in that document define the source-of-truth product scope, user experience, technical stack, routing, UI direction and phased delivery plan for the JARI frontend.

This file exists as a working project-root reference so the frontend delivery plan can be tracked consistently alongside the implementation notes.
